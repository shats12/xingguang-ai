星光AI 桌面助手

Windows 上的一款桌面 AI 助手，带一个可以随手拖着走的小机器人挂件。从 v2.8 起，它会自己学习。

下载

完整包（136 MB）：https://aka.doubaocdn.com/s/q44EOaQtAq

超过 GitHub 网页端 25 MB 的附件上限，所以下载走直链。各版本改了什么见 [Releases](https://github.com/shats12/xingguang-ai/releases)。

功能

- 对话：兼容任意 OpenAI 协议服务 —— 火山方舟（豆包）、智谱、腾讯混元、Gemini、本地 Ollama 都能接
- 自己学习（v2.8 新增）：自动记住你的身份和偏好，把办过的流程攒成经验卡，按你的纠正改行为
- 生成表格、文档、总结，导出到本机
- 桌面挂件：单击弹面板，面板里能搜索并一键启动本机已安装的软件
- 挂件可拖动、可右键切换 迷你 / 标准 / 大 三档尺寸
- 全局热键 Ctrl+Alt+Space 唤起主界面，Ctrl+Alt+Q 退出
- 托盘常驻，不写注册表、不装服务，删文件夹即卸载

快速开始

1. 下载并解压整个文件夹（不要在压缩包里直接双击 exe）
2. 双击 星光AI.exe
3. 首次运行在主界面填写模型接口地址、模型 ID 和 API Key（config.json 里不含任何密钥）
4. 挂件出现在屏幕右下角

关于「自己学习」

学习内容全部留在本机：记忆在 `数据\记忆.json`，经验、教训和规矩在 `数据\学习\`，不会上传，也不会跟着安装包发给别人。对话页右上角「学习」可以看到它学到了什么、单条删除、分类清空、导出微调样本；不想让它学，关掉「自动学习」即可，已经学到的内容会保留。

系统要求：Windows 10 / 11 64 位，解压后约 320 MB。
