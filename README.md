# 星光AI 桌面助手

Windows 上的一款桌面 AI 助手，带一个可以随手拖着走的小机器人挂件。

## 下载

**安装包（132.9 MB）**：https://aka.doubaocdn.com/s/JsE5T959Fg

> 完整包 133 MB，超过 GitHub 网页端 25 MB 的附件上限，所以下载走直链。打开链接直接下载，微信 / QQ 里也能点。

## 功能

- 对话：接入火山方舟（豆包）接口，也可以换成任意兼容 OpenAI 协议的服务
- 生成表格、文档、总结，导出到本机
- 桌面挂件：单击弹面板，面板里能搜索并一键启动本机已安装的软件
- 挂件可拖动、可右键切换 迷你 / 标准 / 大 三档尺寸
- 全局热键 `Ctrl+Alt+Space` 唤起主界面，`Ctrl+Alt+Q` 退出
- 托盘常驻，不写注册表、不装服务，删文件夹即卸载

## 快速开始

1. 下载并**解压整个文件夹**（不要在压缩包里直接双击 exe）
2. 双击 `星光AI.exe`
3. 首次运行在主界面填写火山方舟 API Key 和接入点 ID（`config.json` 里不含任何密钥）
4. 挂件出现在屏幕右下角

系统要求：Windows 10 / 11 64 位，解压后约 317 MB。

## 关于挂件外框

挂件用 Edge WebView2 渲染。Windows 下这种窗口做不出真正的异形透明窗口（试过颜色键抠底、透明窗体、子窗口裁剪，都会露出方块或黑底），所以最终把窗口收到刚好包住机器人，白边只留 2~3 像素。
